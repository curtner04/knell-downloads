# Knell

A dark fantasy action RPG. Downloads only: game builds and update metadata. Source code, settings and credentials are not stored here.

[**Download the Knell launcher for Windows**](https://github.com/curtner04/knell-downloads/releases/latest/download/Knell.exe)

Run Knell.exe once. It installs itself to your user folder, adds Desktop and Start menu shortcuts, downloads the game and keeps it up to date every time you start it.
